# 明石商店未摆商品的货架背景

`cn_7.png`、`cn_8.png` 分别对应国服四列两行网格的第七、第八格。来自已停止任务、尚未购买的真实六商品商店画面；2560×1440 原帧经 `Screenshot.resize_screenshot_to_720p()` 归一化后，使用 `OSShopItem.image` 的同一裁剪及缩放取得 96×96 背景，不包含舰队、货币或账号信息。

这是没有摆商品的货架背景，与 `assets/shop/os/EmptyT*.png` 的售罄物品框不同。只用于 `module/os_shop/akashi_record.py` 的整店完整性校验，不加入通用物品识别器，不改变购买筛选。按服务器及槽位固定匹配，整图相似度至少 0.95 且平均色符合才确认空位；其他位置不能复用，黑屏、未知商品或被漏掉的物品仍拒绝记录。

其他服务器或界面更换背景后，须先校准实际未购货架及正反样本，不降低全局识别阈值。匿名货架回放与漏格保护见 `tests/test_akashi_shop_record_capture.py`。
