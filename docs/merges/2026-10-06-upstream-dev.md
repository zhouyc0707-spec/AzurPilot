## 风险与回退

- 完整原始历史持续增长，本次仍不做有损抽稀；旧密文遇到损坏或未知密钥时暂停相关统计写入，原件保留，需要恢复可读源状态。
- 新交易目录布局的代码回退不能盲目把旧 cache 覆盖回去。先保存回退当时的全部新交易数据，再以同一批次的备份恢复旧布局和配套身份／历史；当前普通统计格式与合入前版本兼容，不因本次更新再次加密。
- Windows 原生和 Edge 在本机验证；macOS／Linux 分支以隔离 Mock 和现有回归覆盖，未在此机器运行对应系统。Intel macOS 已被上游移出 CI，不能称为本次实机通过。
- 构建保留既有字体引用及大 chunk 提示；本次没有执行需要相邻证券服务器工程的完整股票端到端套件，交易恢复与导航使用本库隔离夹具。
- 代码回退应使用本次合并提交的 `git revert -m 1 <合并提交>`，保留之后的其他工作；发生回退冲突时逐段融合，不使用强制重置。
