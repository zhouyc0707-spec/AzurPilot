## 行为变化、限制与回退

1. CL1 新单轮耗时包含准备和战后处理，旧样本保留但不混算；均值变大不能直接解释为脚本变慢。战斗内耗时和经验统计仍有各自口径。
2. 上游事件恢复只针对同服务器、同重置周期和同侵蚀一海域。异常中断保留现场身份；完成一遍有界恢复仍失败时会警告并结束本轮续查，不记成成功。旧近距离／当前视野提示条等待仍保留。
3. Cloudflare 必须显式启用并选择该模式；公网可达性、外部固定入口服务及真实手机配对未验证。其注册服务会处理设备标识、主机名、隧道地址和临时配对凭据，不能把隔离测试说成公网验收或长期稳定性保证。
4. 普通总库正常读写继续不依赖统计加密。旧源、凭据及不可读记录保留和已接受的回退格式限制不变；新增耗时口径不删除货币、掉落或历史明细。
5. 合入使用独立合并提交。运行目录先建立代码回退分支，前端资源及在线一致的 SQLite 备份保存在 D 盘；正常推送并复核 GitHub dev，未经要求不更新 master 或其他远端。代码回退使用 `git revert -m 1 <本次合并提交>`，保留后续提交；前端重新构建或恢复对应资源。不要直接恢复整库覆盖回退后产生的新记录。
6. 本轮完成静态保留、离线流程和浏览器验收；未对每一项历史定制逐项进行真实模拟器验收。运行目录交付后需重启服务加载新后端并刷新页面。
