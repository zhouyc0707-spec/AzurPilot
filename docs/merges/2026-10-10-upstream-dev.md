## 4. 融合时补齐的问题

1. Windows 恢复备份可能超过传统 260 字符路径限制。仅在文件／SQLite I/O 边界采用扩展绝对路径，清单继续保存普通路径。
2. 旧恢复材料的 .db 可能是整库密文。只有 SQLite 文件头的材料使用在线备份，其余按原字节复制；普通来源的真实数据库错误仍传播。
3. rglob 对不可读安全目录可能静默返回空结果。改为显式遍历，链接、越界、拒绝访问阻止不完整迁移发布。
4. 空 WAL 被只读连接创建后可能让旧月度缓存反复失效。空 WAL 不视为业务更新，真实已提交 WAL 仍使缓存失效。
5. 原 PyWebIO 页面仍监听旧库／JSON。改为总库和 WAL 签名；后台预热只读已存在总库，缺库不创建、不迁移。
6. 新岛屿餐厅切换可能在点击交谈前就因主场景标识可见误判成功。必须先操作交谈，再由持续新截图正向确认返回岛内；12 秒不能确认则上抛 GameStuckError，不继续后续路线。
