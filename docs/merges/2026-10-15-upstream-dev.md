## 风险与使用边界

1. `ActionPointCheckInterval` 默认 0，保持常规完整面板检查频率；用户设为正数才启用间隔跳查。新缓存不会延续到不同实例、服务器、库存变更或异常恢复，真实提速幅度需新运行日志确认。
2. 末日清券默认服务器时间 09:30；末日当天更早运行会延后本次建造任务。清券和中间批次快速完成沿用此前确认的策略，实际消耗由游戏执行发生，代码回退不能撤销已消耗资源。
3. 心情预留默认 0，不改变现有控制线；设置正值后，心情不足触发的等待可能更长，目标受当前恢复上限约束。
4. 新科技扫描默认 95—125，仅模板／新增设置采用新默认，不强改已有心智扫描范围。身份疑点需要用户核对；原心智严格等级保护优先保留。
5. Windows 隔离浏览器测试的子进程回收较慢，需要按本轮 PID／命令行精确清理，未停止运行目录服务。旧版一次加载超时在相同 5 秒限制下独立复验通过，证据分别保留；不能据单次复验保证所有机器的冷加载时长，未以放宽断言掩盖。
6. Python 运行进程不会自动重新导入源码；当前任务结束后重启服务，并刷新浏览器使用新构建。本轮不主动中断真实任务。
