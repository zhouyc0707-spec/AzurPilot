# 取消上游本地统计加密

本次按用户要求在当前 `dev` 分支取消上游本地统计加密，保留其余上游更新和全部定制统计逻辑。GitHub 与 Gitee 均交付 `dev`；`master` 不参与本次交付。

## 实现

- 默认统计服务改用 `PlainStatisticsStore`。CL1 全部字段保存为 JSON，掉落、资源与日报直接使用 SQLite 业务列，舰船经验保存为 JSON，短猫汇总为 CSV，每日备份为普通 SQLite。
- 不再依赖 OS 凭据、TPM 或 Broker，不维护加密校验链及后台深检查。保留线程／进程协调锁、SQLite 写事务、错误回滚、原子文件替换、只读缓存与上游传输绘图优化。
- 黄币／紫币完整历史、月初残留、行动力与海里数、委托科研数据、舰船经验、日报正文和扩展字段继续保留。用户业务表、额外列及触发器不会因转换丢失或重复触发。
- `Vault` 及平台凭据代码保留作旧格式兼容和隔离测试；不会为正常运行创建新密文。旧格式的解密只读验证，不改写旧凭据。
- 原子替换改用同目录短随机临时文件名，避免设备标识与迁移备份目录叠加后超过 Windows 路径限制。
- 登录、账号保险库、交易密钥、reCAPTCHA 与通信认证使用各自的保护。取消范围限于本次上游引入的本地统计加密。

## 数据迁移和保护

先复制并验证真实数据，再在副本解密、逐行回读。所有副本通过后才发布；发布失败或进程中断时恢复整批原件。旧描述、本机凭据和原密文备份继续保留。不可读记录、未完成的旧提交或未知加密扩展字段不会被删除、归零或静默忽略。

每日归档解除上游 V2 外层加密；没有内层 V1／V2 的 SQLite 归档保持原始字节，若有内层 V1／V2 则无损转换这些字段。8 份历史 CL1 备份仍各含 2026 年 2、3 月两条早期 AES 原件，本次共保留 16 条，未作删除；当前活动库中这两个无法解密月份已按此前用户决定删除，取消本次上游加密不能补回缺失的旧密钥。

## 验证

- 普通统计、旧格式迁移、回滚、并发、额外字段、长文件名与混合归档测试：28 项通过；与旧加密兼容用例共 133 项通过。
- 相关统计回归：149 项通过。
- 资源窗口与黄紫币原始点测试：9 项通过。
- 旧加密兼容测试保留；旧实现不参与普通统计写入。
- 基础 Python lint、语法及补丁空白检查通过。本次未修改前端或 API 契约，不需要重新生成前端代码。

真实副本核验通过：301,151 条活动数据库记录、3 份统计日志与 16 份每日归档，迁移前后业务摘要全部一致。归档原始内容共 583,155,712 字节；14 项配置／身份保护文件保持一致，实际凭据与运行目录原件未被副本验收修改。运行目录最终迁移、提交号及远端同步结果在交付验收后补充。

## 回退

代码回退使用 `git revert <本次功能提交>`，保留后续其他提交；回退前先停止 GUI 和所有统计写者，并另存最新普通统计。旧 V2 代码不能直接读取迁移后的普通库，需要恢复同一批次的 V2 原件和匹配的旧描述／凭据；原件在自动迁移的 `original/` 与独立交付备份中保留。若迁移后继续采集了新统计，须先为最新数据制定重新加密或合并恢复方案，不能用旧备份直接覆盖新增历史。所有回退资料均为本机私有文件，不提交公开仓库。
